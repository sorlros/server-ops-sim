# Product Vision

## 목표

서버 장기 운영 경험이 적은 개발자가 실제 운영에서 자주 만나는 장애를 안전하게 반복 학습하도록 돕는다.

## 대상 사용자

- 풀스택/백엔드 개발 경험은 있으나 운영 장애 대응 경험이 적은 개발자
- 로그, 메트릭, 프로세스, 서비스 상태를 연결해 원인을 추론하는 훈련이 필요한 사용자

## 핵심 경험

1. 장애 알림을 받는다.
2. 웹 터미널에서 관측 명령을 실행한다.
3. 로그/메트릭/서비스 상태를 해석한다.
4. 안전한 조치를 실행한다.
5. health check와 점수/리포트로 결과를 확인한다.

## MVP 원칙

- 실제 서버/컨테이너 조작 없이 상태머신으로 구현한다.
- 정답 하나가 아니라 허용 가능한 해결 경로를 지원한다.
- 도메인 로직은 UI 없이 테스트 가능해야 한다.
